# Atributos de calidad

| ID   | Atributo de calidad                          | Escenario de calidad                                                                                                                                                                                    |
| ---- | -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AC01 | **Seguridad y aislamiento multiinstitución** | Ninguna institución puede ver ni modificar datos de otra, aunque compartan la misma plataforma y la misma base de datos. Los datos personales de menores se protegen conforme a la Ley 29733.           |
| AC02 | **Adaptabilidad / configurabilidad**         | Un tipo nuevo de institución o un cambio en los módulos de un servicio se resuelve cargando una plantilla o activando funciones, sin cambiar código ni volver a desplegar.                              |
| AC03 | **Escalabilidad**                            | El sistema debe soportar picos de carga en periodos de matrícula, cierre de bimestre y generación masiva de libretas y certificados, escalando solo los servicios afectados.                            |
| AC04 | **Rendimiento**                              | Las consultas frecuentes (portal del apoderado, registro de notas y asistencia) deben responder rápidamente incluso con muchos usuarios simultáneos. La generación de PDF no debe bloquear la interfaz. |
| AC05 | **Disponibilidad y resiliencia**             | La caída de un servicio no crítico (aula virtual, simulacros, workers de PDF) no debe impedir operar los módulos críticos (matrícula, notas, asistencia, pagos).                                        |
| AC06 | **Integridad y no repudio de documentos**    | Un documento firmado no puede alterarse sin que se detecte, y siempre se sabe quién lo firmó y cuándo.                                                                                                  |
| AC07 | **Mantenibilidad**                           | Cada microservicio puede modificarse, probarse y desplegarse de forma independiente; las reglas de negocio no dependen de la tecnología.                                                                |
| AC08 | **Interoperabilidad**                        | El sistema se integra con Firma Perú, SIAGIE, RENIEC, SUNAT y pasarelas de pago, y puede cambiar de proveedor sin afectar el negocio.                                                                   |
| AC09 | **Observabilidad**                           | Cualquier operación puede rastrearse de extremo a extremo entre servicios (trazas, registros y métricas) para diagnosticar fallas.                                                                      |
