# Actores

## Actores humanos

| Actor                                | ¿Qué necesita realizar?                                                                                                                                    |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Superadmin de plataforma**         | Dar de alta organizaciones, administrar planes de suscripción, plantillas por tipo de institución, catálogos globales (MINEDU) y monitorear la plataforma. |
| **Promotor / propietario**           | Configurar su organización y sus servicios educativos, activar funciones, revisar indicadores y finanzas.                                                  |
| **Director**                         | Dirigir el servicio educativo: personal, carga académica, cierre de periodos, aprobación y **firma digital** de actas, certificados y constancias.         |
| **Coordinador académico / de ciclo** | Gestionar programas, secciones, horarios, carga docente y simulacros.                                                                                      |
| **Secretaría académica**             | Matricular, gestionar expedientes, traslados y retiros; solicitar la emisión de documentos; exportar a SIAGIE.                                             |
| **Tesorería / caja**                 | Definir cronogramas de pago, registrar cobros, emitir comprobantes y gestionar becas y convenios.                                                          |
| **Docente**                          | Registrar asistencia y calificaciones de sus aulas, publicar tareas y recursos en el aula virtual.                                                         |
| **Tutor**                            | Hacer seguimiento a sus secciones: alertas, tutoría y comunicación con apoderados.                                                                         |
| **Profesional EBE**                  | Terapeuta o psicólogo: registrar el perfil NEE, el POI, las sesiones PRITE y las visitas SAANEE.                                                           |
| **Estudiante**                       | Consultar notas, asistencia, horario, tareas, pagos y descargar sus documentos.                                                                            |
| **Apoderado**                        | Consultar la información de sus hijos o representados, pagar en línea y recibir comunicados.                                                               |
| **Verificador externo**              | Persona o entidad (universidad, empleador) que valida la autenticidad de un documento escaneando su código QR, sin cuenta en la plataforma.                |

## Sistemas externos

| Actor                              | ¿Qué necesita realizar?                                                                                                                                                                                 |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Agente Firma Perú**              | Software de la PCM instalado en la computadora del firmante. Descarga el PDF, lo firma con el certificado digital del usuario (DNIe o certificado de una entidad acreditada) y devuelve el PDF firmado. |
| **Servicio de Firma Perú (PCM)**   | Emite el token de autorización que necesita el agente para firmar en nombre de la plataforma.                                                                                                           |
| **SIAGIE (MINEDU)**                | Recibir las exportaciones de nóminas, notas y actas de las modalidades reguladas.                                                                                                                       |
| **RENIEC**                         | Validar el DNI y los datos de identidad de estudiantes, apoderados y personal.                                                                                                                          |
| **SUNAT / OSE**                    | Validar y registrar los comprobantes de pago electrónicos (boletas y facturas).                                                                                                                         |
| **Pasarela de pagos**              | Procesar pagos en línea con tarjeta, billeteras y otros medios.                                                                                                                                         |
| **Proveedor de correo / WhatsApp** | Entregar notificaciones, códigos de verificación y comunicados.                                                                                                                                         |
