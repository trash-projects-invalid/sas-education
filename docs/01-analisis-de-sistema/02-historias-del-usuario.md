# Historias de usuario

| ID   | Historia de usuario                                                                                                                                                                |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| HU01 | Como superadmin, quiero registrar una organización y crear sus servicios educativos eligiendo una plantilla por tipo de institución, para que empiece a operar sin programar nada. |
| HU02 | Como promotor, quiero activar o desactivar funciones de cada servicio educativo, para que la plataforma muestre solo los módulos que mi institución usa.                           |
| HU03 | Como usuario, quiero iniciar sesión una sola vez y cambiar entre las instituciones y servicios donde tengo un rol, para trabajar con la información correcta.                      |
| HU04 | Como coordinador académico, quiero configurar programas, periodos, cortes y secciones con los nombres propios de mi tipo de institución, para organizar el año, semestre o ciclo.  |
| HU05 | Como secretaría, quiero registrar estudiantes y apoderados validando su DNI, para tener datos de identidad correctos.                                                              |
| HU06 | Como secretaría, quiero matricular estudiantes por sección o por curso, incluidos traslados, convalidaciones y retiros, para mantener la nómina al día.                            |
| HU07 | Como coordinador académico, quiero asignar docentes a aulas y armar horarios, para organizar la carga académica.                                                                   |
| HU08 | Como docente, quiero registrar la asistencia de mis estudiantes, para hacer seguimiento a su participación.                                                                        |
| HU09 | Como docente, quiero registrar calificaciones según el esquema de mi servicio (competencias, vigesimal, descriptivo o puntaje), para evaluar a mis estudiantes.                    |
| HU10 | Como director, quiero cerrar un corte o un periodo, para bloquear las notas y generar la situación final y las actas.                                                              |
| HU11 | Como secretaría, quiero generar libretas, constancias, actas y certificados en PDF, individualmente o por lotes, para entregarlos a estudiantes y autoridades.                     |
| HU12 | Como director, quiero firmar digitalmente los documentos con Firma Perú usando mi certificado, para que tengan validez legal.                                                      |
| HU13 | Como verificador externo, quiero escanear el código QR de un documento, para comprobar que es auténtico y no fue modificado.                                                       |
| HU14 | Como tesorería, quiero definir cronogramas de pago y registrar cobros con su comprobante electrónico, para controlar los ingresos.                                                 |
| HU15 | Como apoderado, quiero ver las notas, la asistencia y los pagos de mis hijos y pagar en línea, para estar informado y al día.                                                      |
| HU16 | Como coordinador de academia, quiero programar simulacros y publicar el ranking, para medir el avance de los estudiantes.                                                          |
| HU17 | Como profesional EBE, quiero registrar el perfil NEE y el plan de orientación individual de un estudiante, para atender sus necesidades.                                           |
| HU18 | Como director o tutor, quiero enviar comunicados y recibir alertas de riesgo (inasistencia, bajo rendimiento, deuda), para intervenir a tiempo.                                    |
| HU19 | Como secretaría, quiero exportar nóminas y actas al formato SIAGIE, para cumplir con el MINEDU.                                                                                    |
| HU20 | Como estudiante, quiero acceder al aula virtual para revisar recursos y entregar tareas.                                                                                           |
